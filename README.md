\# DimaMaak — Intelligent Maternal Health Monitoring System



> \*\*“For women who give birth alone. For doctors who are too far.”\*\*



\## 🌍 Problem Statement



In many rural areas, pregnant women face critical risks due to lack of medical access, distance from hospitals, and low literacy levels. Monitoring during pregnancy and childbirth is often impossible, leading to preventable maternal complications.



\## 💡 Solution



\*\*DimaMaak\*\* is an intelligent IoT + web-based healthcare system designed to monitor pregnant women in real time and alert doctors instantly in case of risk.



It combines:



\* 🧠 Smart wearable device (ESP32-based)

\* 🏥 Real-time medical dashboard

\* 📡 Automated alert \& SMS system

\* 🔔 Intelligent contraction detection algorithm



\## ⚙️ Key Features



\* Real-time monitoring of vital signs (heart rate, SpO2, blood pressure)

\* Contraction tracking using physical buttons + timing algorithm

\* Automated pregnancy phase detection (Latent / Active / Transition / Emergency)

\* Instant SMS alerts to doctor, family, and hospital in emergencies

\* Audio guidance system for low-literacy patients

\* Doctor dashboard with patient history \& live data visualization

\* Automated appointment reminders using N8N workflows



\## 🧠 Intelligence Behind the System



The system analyzes contraction patterns using clinical rules:



\* \*\*5-1-1 rule\*\* → Active labor detection

\* \*\*3-1-1 rule\*\* → Emergency phase detection

\* Continuous time-series analysis of contraction duration \& intervals



\## 🛠️ Tech Stack



\* \*\*Hardware:\*\* ESP32, GPS, GSM SIM800L, sensors, LCD, buzzer

\* \*\*Frontend:\*\* React.js / Next.js + Tailwind CSS

\* \*\*Backend:\*\* Node.js / Express

\* \*\*Database:\*\* PostgreSQL

\* \*\*Automation:\*\* N8N (SMS \& reminders)

\* \*\*Communication:\*\* HTTP + GSM fallback (offline support)
